# AI-Based Smart Campus Complaint Management System

## Project Description
The Smart Campus Complaint Management System is a web application that helps students submit and track campus complaints. It also allows the admin to manage complaints and update their status.

## Features
- Submit campus complaints
- Track complaints using Complaint ID
- Admin dashboard to view complaints
- Update complaint status
- Machine Learning-based complaint category prediction
- Store complaint data using SQLite database

## Technologies Used
- Python
- Flask
- SQLite
- HTML
- CSS
- Machine Learning
- Scikit-learn

## Machine Learning
The project uses TF-IDF for text feature extraction and Multinomial Naive Bayes to predict the complaint category from its description.

## How to Run the Project
1. Install Python.
2. Install the required libraries:
   `pip install flask scikit-learn`
3. Run the application:
   `python app.py`
4. Open the local URL displayed in the terminal in your browser.
